forms.robot-1.9.11.owx is ROBOT's OWL/XML of forms.ofn, byte for byte, kept
as the evidence of how OWL API writes what the OWL/XML Recommendation does not
settle (literals, SWRL rules). Do not edit or reformat it; make it again with
the commands below. Two runs give the same bytes.

The import of forms.ofn resolves, through a catalog, to an empty ontology of
that IRI (as tools/corpus/robot-ofn.sh and robot-owx.sh do). From the
repository root, with JAVA and ROBOT set:

  tmp=$(mktemp -d)
  printf 'Ontology(<http://example.org/imported>)\n' > "$tmp/imported.ofn"
  cat > "$tmp/catalog.xml" <<'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<catalog xmlns="urn:oasis:names:tc:entity:xmlns:xml:catalog">
  <uri name="http://example.org/imported" uri="imported.ofn"/>
</catalog>
EOF
  "$JAVA" -jar "$ROBOT" convert --catalog "$tmp/catalog.xml" \
    -i tests/owx/forms.ofn --format owx -o tests/owx/forms.robot-1.9.11.owx
  rm -r "$tmp"
