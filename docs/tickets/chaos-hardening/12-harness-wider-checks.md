# 12: Harness: splice, token-sequence, `fix_all`, external prefixes, SPARQL and rename graph checks, squeeze, snippets

**What to build:** In tests/chaos.rs: (1) a splice assertion for every edit set that inserts or removes a declaration (undeclared-prefix quick fixes, "Add all missing prefixes", the JSON-LD undefined-prefix fix, completion items with `additional_text_edits`, SPARQL `add_prefix` through its code action, "Remove unused/duplicate prefix"): the token sequence after equals the sequence before with the directive's tokens inserted or removed at one index whose predecessor ends a document-level directive or statement (or `k == 0`, or only comments precede); it runs on inputs with parse errors too.
